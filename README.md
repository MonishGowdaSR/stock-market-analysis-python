# Stock Market Analysis with Data Visualization using Python

A Python-based stock market analysis application that retrieves historical stock data and generates visualizations to help analyze price trends, returns, moving averages, and relationships between selected stocks.

## Features

- Fetch historical stock market data using Yahoo Finance
- Visualize stock closing prices
- Calculate and visualize 50-day and 200-day moving averages
- Calculate and visualize daily returns
- Generate a correlation heatmap for selected stocks
- Simple graphical user interface using Tkinter
- Input stock ticker and date range through the application

## Technologies Used

- Python
- Tkinter
- yfinance
- Pandas
- Matplotlib
- Seaborn
